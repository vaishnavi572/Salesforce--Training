# Salesforce Interview Readiness Bootcamp - Day 4

## Lightning Web Components (LWC)

### 📌 Project Overview
This project is my first Lightning Web Component (LWC) built as part of the Salesforce Interview Readiness Bootcamp. The goal was to understand how Salesforce user interfaces are created using Lightning Web Components and how they fit into the overall Salesforce architecture.

---

## 🚀 What is Lightning Web Component (LWC)?

Lightning Web Components (LWC) is Salesforce's modern UI framework built on standard web technologies such as HTML, JavaScript, and CSS. It enables developers to create fast, reusable, and maintainable user interfaces that can interact with Salesforce data through Apex.

---

## 🛠️ What I Built

I created a **Placement Management System Home Page** that includes:

- Placement Portal heading
- Current Date
- Welcome Student message
- Number of Companies
- Number of Jobs
- Applications Submitted
- Interactive buttons using JavaScript
- Basic data binding with variables

The values are currently hard-coded and will later be connected to Apex classes and Salesforce data.

---

## 📂 LWC File Structure

### `placementHome.html`
Responsible for:
- Page layout
- Text and headings
- Buttons
- Displaying data

### `placementHome.js`
Responsible for:
- Business logic
- Variables
- Button click events
- Updating values dynamically

### `placementHome.js-meta.xml`
Responsible for:
- Making the component available in Lightning App Builder
- Defining where the component can be used (App Page, Home Page, Record Page)
